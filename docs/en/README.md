# sSettings 1.x for Evolution CMS

sSettings adds project settings to the Evolution CMS manager. Use it to store
site-wide values such as contact details, image paths and links. Settings are
available to site templates under keys prefixed with `sset_`.

- [Getting started](getting-started.md)
- [Use in Blade](use-in-blade.md)

See [GitHub Releases](https://github.com/Seiger/sSettings/releases) for the changes
in each release.
