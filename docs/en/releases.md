# Releases and compatibility

| Release line | Requirements |
| --- | --- |
| 2.x | PHP 8.4 or 8.5, Evolution CMS 3.5.8 or later in the 3.x line, and EvoUI 1.3 or later in the 1.x line. |
| 1.x | The package declares PHP `^8`. Check the requirements of your installed Evolution CMS version. |

The 2.x package checks for schema writes, permissions, multilingual settings,
translations and URLs also pass on PHP 8.6.0 RC5. This result applies to the
release candidate.

Use the version menu to open the documentation for your installed release line.
See the [sSettings release notes](https://github.com/Seiger/sSettings/releases)
for changes in individual versions.
