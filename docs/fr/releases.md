# Versions et compatibilité

| Branche | Prérequis |
| --- | --- |
| 2.x | PHP 8.4 ou 8.5, Evolution CMS à partir de 3.5.8 dans la branche 3.x et EvoUI à partir de 1.3 dans la branche 1.x. |
| 1.x | Le paquet déclare PHP `^8`. Vérifiez les prérequis de votre version d’Evolution CMS. |

Les vérifications de l’enregistrement du schéma, des permissions, des réglages
multilingues, des traductions et des URL ont aussi réussi pour 2.x avec
PHP 8.6.0 RC5. Ce résultat concerne cette version candidate.

Dans le menu des versions, sélectionnez la branche installée. Les changements
de chaque version figurent dans les [notes de publication de sSettings](https://github.com/Seiger/sSettings/releases).
