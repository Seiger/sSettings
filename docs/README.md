# sSettings Documentation

![sSettings manager in Evolution CMS with project settings and configuration tabs](assets/img/ssettings-manager.png)

sSettings is an Evolution CMS manager module for project-specific settings that
are stored as `sset_*` system settings and can be reused in Blade templates,
Evolution chunks, snippets, and frontend layouts.

## Languages

- [English](en/README.md)
- [Ukrainian](ua/README.md)
- [Polish](pl/README.md)
- [German](de/README.md)
- [French](fr/README.md)

Each language includes:

- a manager user guide;
- a developer guide;
- a frontend usage guide.

The 2.x guides apply to PHP 8.4 and 8.5. The public site builds current guides
from `2.x` and the archived guides from `1.x`. See [GitHub Releases](https://github.com/Seiger/sSettings/releases)
for individual version notes.
