# sSettings Documentation

sSettings is an Evolution CMS manager module for project-specific settings that
are stored as `sset_*` system settings and can be reused in Blade templates,
Evolution chunks, snippets, and frontend layouts.

## Languages

- [English](en/README.md)
- [Ukrainian](ua/README.md)
- [Polish](pl/README.md)
- [German](de/README.md)
- [French](fr/README.md)

Each language includes:

- a manager user guide;
- a developer guide;
- a frontend usage guide.
