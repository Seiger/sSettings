# Релізи й сумісність

| Гілка | Вимоги |
| --- | --- |
| 2.x | PHP 8.4 або 8.5, Evolution CMS від 3.5.8 у гілці 3.x та EvoUI від 1.3 у гілці 1.x. |
| 1.x | Пакет декларує PHP `^8`. Перевірте вимоги встановленої версії Evolution CMS. |

Перевірки запису схеми, прав доступу, багатомовних налаштувань, перекладів і
URL для 2.x також пройшли на PHP 8.6.0 RC5. Цей результат стосується кандидата
у випуск.

У меню версій виберіть гілку встановленого пакета. Зміни в окремих версіях
описані в [примітках до релізів sSettings](https://github.com/Seiger/sSettings/releases).
