# Посібник користувача

## Відкриття sSettings

У менеджері Evolution CMS відкрийте **Інструменти -> Користувацькі
налаштування**. У модулі є два таби:

- **Налаштування** - редагування значень.
- **Конфігурація** - редагування табів, полів, назв, описів і типів полів.

Інтерфейс працює на evo-ui та Livewire, тому перемикання табів і збереження
оновлюють тільки область модуля.

## Екран налаштувань

Екран Налаштування показує один конфігураційний таб за раз. Кожен рядок поля
містить:

- назву поля;
- системний ключ, наприклад `[(sset_phone)]`;
- поле вводу;
- опис поля під полем вводу.

Опис пояснює, де значення використовується на сайті. Після змін натисніть
**Зберегти**.

## Типи полів

| Тип | Для чого |
| --- | --- |
| Text | Короткі значення: email, телефон, URL або ID. |
| Textarea | Великі тексти, HTML-фрагменти або скрипти відстеження. |
| TextareaMini | Короткі багаторядкові значення. |
| RichText | Форматований контент у manager rich editor. |
| DropDown List Menu | Одне значення з компактного dropdown. |
| Listbox | Одне або кілька значень з високого списку. |
| Radio Options | Одне значення з видимих опцій. |
| Checkbox Group | Кілька значень з видимих опцій. |
| Image | Шлях до зображення, вибраний через менеджер. |
| File | Шлях до файла, вибраний через менеджер. |
| Checkbox | Увімкнено або вимкнено. |
| Divider | Візуальний розділювач; значення не зберігає. |

Checkbox зберігається як `1` або `0`. Поля з опціями використовують рядки
`value`/`label`. Плюс додає опцію після поточного рядка, кошик видаляє,
стрілки рухають вручну, а drag handle міняє порядок списку.

## Екран конфігурації

Екран Конфігурація змінює схему, за якою будується екран Налаштування.

Рядок таба містить:

- drag handle;
- ключ таба;
- перекладену назву таба;
- компактні дії для додавання таба, додавання поля або видалення таба.

Рядок поля містить:

- drag handle;
- назву поля;
- системний ключ;
- опис поля;
- чип типу поля;
- дії для налаштування, додавання після поточного і видалення.

Натисніть іконку налаштувань поля, щоб відкрити компактне модальне вікно.

## Перетягування

Використовуйте drag handle, щоб змінювати порядок табів або полів. Поля можна
переміщувати всередині таба або між табами. Опції в модалці поля мають той
самий EvoUI drag handle і стрілки вгору/вниз для точного ручного порядку.

## Системні ключі

Кожне поле зі значенням створює системне налаштування Evolution:

```text
назва поля: phone
системний ключ: sset_phone
тег у шаблоні: [(sset_phone)]
```

Зміна назви поля змінює системний ключ після збереження Конфігурації.

## Збереження і права

Екран Налаштування зберігає значення. Екран Конфігурація зберігає схему і
синхронізує системні налаштування. Для Конфігурації потрібне право Evolution
`settings`.

Якщо файл схеми недоступний для запису, sSettings покаже помилку доступу до
файла.

## Типові проблеми

- Якщо поле зникло, перевірте таб Конфігурація і збережіть схему.
- Якщо значення не видно на фронтенді, очистіть кеш Evolution після збереження.
- Якщо Конфігурація недоступна, перевірте право `settings` у ролі менеджера.
- Якщо назва виглядає як `sSettings::global.email`, для активної мови немає
  перекладу.
