# Документація sSettings

sSettings додає компактний екран налаштувань у менеджер Evolution CMS. Модуль
використовується для загальних значень сайту: email, телефони, соціальні
посилання, скрипти відстеження, файли, зображення та проєктні прапорці.

- [Посібник розробника](developer-guide.md)

## Основні можливості

- Редагування проєктних налаштувань у компактному evo-ui інтерфейсі.
- Групування полів у таби, наприклад Основна інформація і Соціальні мережі.
- Налаштування табів і полів із менеджера за наявності права `settings`.
- Збереження значень як системних налаштувань Evolution із префіксом `sset_`.
- Використання значень у Blade або Evolution шаблонах через `evo()->getConfig()`.
