# sSettings 1.x для Evolution CMS

sSettings додає до менеджера Evolution CMS налаштування проєкту. У модулі
можна зберігати контактні дані, шляхи до зображень і посилання. Значення
доступні в шаблонах сайту за ключами з префіксом `sset_`.

- [Швидкий старт](getting-started.md)
- [Використання в Blade](use-in-blade.md)

Для sSettings 2.x відкрийте [актуальні посібники](https://seiger.github.io/sSettings/uk/).
Зміни в окремих версіях описані в [релізах на GitHub](https://github.com/Seiger/sSettings/releases).
