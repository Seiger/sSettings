# Wersje i zgodność

| Linia wydań | Wymagania |
| --- | --- |
| 2.x | PHP 8.4 lub 8.5, Evolution CMS od 3.5.8 w linii 3.x i EvoUI od 1.3 w linii 1.x. |
| 1.x | Pakiet deklaruje PHP `^8`. Sprawdź wymagania zainstalowanej wersji Evolution CMS. |

W linii 2.x testy zapisu schematu, uprawnień, ustawień wielojęzycznych, tłumaczeń
i adresów URL przeszły również na PHP 8.6.0 RC5. Wynik dotyczy tej wersji
kandydującej do wydania.

Z menu wersji wybierz zainstalowaną linię wydań. Zmiany poszczególnych wersji
opisano w [informacjach o wydaniach sSettings](https://github.com/Seiger/sSettings/releases).
