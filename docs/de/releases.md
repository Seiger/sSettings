# Versionen und Kompatibilität

| Versionsreihe | Anforderungen |
| --- | --- |
| 2.x | PHP 8.4 oder 8.5, Evolution CMS ab 3.5.8 innerhalb der Reihe 3.x und EvoUI ab 1.3 innerhalb der Reihe 1.x. |
| 1.x | Das Paket gibt PHP `^8` an. Prüfen Sie die Anforderungen Ihrer installierten Evolution-CMS-Version. |

Die Prüfungen zum Speichern des Schemas, zu Berechtigungen, mehrsprachigen
Einstellungen, Übersetzungen und URLs waren für 2.x auch unter PHP 8.6.0 RC5
erfolgreich. Das Ergebnis gilt für diesen Release Candidate.

Wählen Sie im Versionsmenü die installierte Versionsreihe aus. Änderungen
einzelner Versionen stehen in den [sSettings-Versionshinweisen](https://github.com/Seiger/sSettings/releases).
